# Model check, 28 September 2026 (second full run): Haiku and Sonnet on 119 questions

**Setup.** Same 119 questions, batches and prompt as the first run
(`2026-09-28-haiku.md`): realmarket's tools only, live data (Yahoo Finance, TCMB EVDS, GDELT),
no web search, server instructions as the model's own. Claude Haiku 4.5 ran the whole set on
the code of `c0a5800`; the five fixes it prompted went in (`8940e21`), its eight affected
questions were re-run on them, and Claude Sonnet ran the whole set on the fixed code. Every
failure, and every answer containing words that could carry a verdict, was read by hand.

First run, for comparison: Haiku 94 / 119 automatic, about 112 correct after its fixes.

Haiku's five: two portfolio questions answered from price summaries instead of
`analyze_portfolio` (one of them adds up a gain itself), a target-price question whose answer
computes "80% of the sector" and calls a P/B "quite high", an "at the bottom?" answer that
mislabels a drawdown ("21.3 weeks"), and one news question during a GDELT rate limit, which
it reported as such. Sonnet's four automatic failures in the first scoring were all the
scorer's: a figure from a quality flag, "BIST 100", and "kaynaklı" meaning "sourced".

## What the run found in the tools, and what was changed

1. **"GOLD" is a mining share on Yahoo.** Asked for gold, Haiku passed `GOLD`, which Yahoo
   resolves to Barrick Gold's share: +71% reported as gold's return, where gold rose 12.1%.
   The Yahoo provider now refuses `GOLD` and names `GC=F`.
2. **`check_setup` listed sources, not tools.** Three times Haiku checked the setup, read that
   valuation and financial statements work, and still answered "not available" without
   calling the tool. Its facts now name the tool for each kind of question, and its
   description no longer suggests calling it before every report.
3. **A purchase on a holiday bought at the previous close.** `portfolio_real_return` priced
   money put in on 1 July 2023 (a holiday) at 27 June's close, while `compare_real_return`
   used 3 July: two tools, two answers (28,278 vs 30,731 TL). Purchases now buy at the next
   session, and a month alone ("2023-07") is accepted as its first session, as in
   `analyze_portfolio`.
4. **Alternatives only in percent.** With an amount, Haiku multiplied gold's +246.7% itself
   (and got 138,680.91 TL for 138,664.40). The facts now give every alternative in money.
5. **Dividends not entered.** Haiku added the source's dividends to a realised loss itself;
   the facts now state the result with them, per holding and for the account.

Re-run of the eight affected Haiku questions: 8 / 8.

The scorer counts figures stated in quality flags, ignores index names ("BIST 100") and no
longer reads "kaynaklı bir veri" (sourced data) as a cause.
